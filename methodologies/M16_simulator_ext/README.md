## Reading of the plan (written BEFORE the first run)
The plan gives one line per step. Where it is silent I took the simplest reading consistent with it; any of these could be wrong.

**Common.** Reference = frozen plan-2 S3 (hash `0d1b7c074d80`), re-simulated in this harness with the plan-2 streams (`seed + 10000 + race index`, 1,000 draws). Each step is added to S3 alone. Only the step's new parameters and `tau` are searched (coordinate search, objective = plan-2 mean RPS, 300 draws, streams `1000 + i`, dev races only, at most 30 distinct configurations including the start); every other S3 parameter (`dnf_scale`, regime, `kappa`) stays frozen. The S3 random stream is consumed in the same order in every variant; whatever is new is drawn from a second generator, so a difference to S3 is not a shifted stream. Decoder D0 = sort by expected position with exact ties broken by driverId (`D0_free` of M17); grid order with driverId tie-break. 10,000 bootstrap resamples of races, seed 0. Verdicts per metric by the CI rule; "dev only" for everything secondary.

**S4 position-dependent discount.** Plackett-Luce sampled stage by stage with a temperature per stage: stage 1 is S3's key (`tau`), 2nd and 3rd place use `tau*m2`, `tau*m3`, the rest of the field `tau*m4`. Stages 2+ use fresh Gumbel draws (from the second generator) because one shared Gumbel draw across stages would not be Henery's model. Retirees stay behind all finishers with S3's tie-break. `m = 1` is distributionally S3 but not the same draws, so "S4 off" = the S3 code path; the neutral S4 is run as a noise diagnostic. m < 1 flattens later stages (the classical Henery/Stern discount).

**S5 normal draws with team shocks.** `key = tau*z + sigma_i*eps_i + tau_team*eta_team`. `eps` is S3's own Gumbel draw mapped to a normal by the quantile map (same stream, normal marginal); `eta` is a shared team draw (the teams of a race = `lineage`). `sigma_i = sigma*(1 + e_exp*[driver has < 20 earlier starts])*(1 + e_wet*rain_forecast)`; rain forecast is the 0/1 plan-2 weather flag, experience is counted from the entry table (pre-race). The regime multiplier scales all the noise. Starting point `sigma = pi/sqrt(6)` (the Gumbel sd), `tau_team = e_exp = e_wet = 0` is the plain Thurstone-normal model; it is not S3 (normal instead of Gumbel tails). Joint metric: log-loss of "both cars of a two-car team score points" (positions <= 10), probability clipped to [1e-4, 1-1e-4], mean over the race's two-car teams, reported for S3, S4, S5, S6 alike.

**S6 parameter uncertainty.** Before each draw the utilities `z_i` are perturbed by `c_eff * N(0, Sigma_race)`, where `Sigma_race` is the Laplace covariance of the entries' utilities `u = a + b + g + beta.x` from the walk-forward fit that produced the score (A5 machinery: Hessian of the penalised unnormalised objective at the fitted parameters, finite differences of the analytic gradient, full covariance, so teammates share car uncertainty). The walk is replayed exactly as in plan 2 (refit before every race, warm start), and the replayed scores equal the stored plan-2 scores to 0.0. `c_eff = c*(1 + c_early*[round <= 3])`, `c = 1` is the literal Laplace interval. "Wider at the start of a season and after a rule change": the Laplace interval itself is wider for a new car-season (little data, prior only); `c_early` adds a fitted extra widening for the first three rounds. **I do not fit a separate rule-change width:** the dev block has one rule change (2022), too few races to fit a separate parameter; the 2022 gains are reported descriptively. Caveats: fits stop at 150 iterations, the decayed likelihood is a power likelihood, the intervals are conditional on the model, so `c` absorbs part of the mismatch. S6 with `c = 0` is S3 bitwise.

**S7 mean-reverting season carry-over.** The plan-1 model already has the AR(1) tie `lam*(b_s - rho*b_{s-1})^2` with fixed `rho = 0.8` and one innovation size. S7 = `rho` (phi) fitted, and the innovation variance multiplied by `rule_mult` in rule-change seasons (penalty weight `lam/rule_mult` for the car effects of 2014, 2017, 2022, 2026; a fact known in advance). `rule_mult = 1` is the plan-2 objective bitwise. phi and rule_mult were first fitted by the plan-2 latent objective (mean Spearman on dev, refit every 4 races, as `tune_pick`; run `0652`, **superseded**: PLAN3 §4 says each M16 step is fitted by RPS, so in the revision the same 25 configurations were re-scored by simulator RPS and the RPS pick is the declared S7, see Results), 25 grid configurations; the S3 simulator is then run on the new scores with the frozen S3 parameters (primary) and with `tau` re-fitted by RPS (secondary). The tau re-fit adds at most 3 configurations (total <= 28).

**Calibration gate and the declared interaction.** `grid_slot_calibration` is run on every new matrix. I read "passes" as: mean predicted P(finish in the grid slot) is within 2 percentage points of the realised share (the plan gives no number: this threshold is mine, not the plan's; M17's README only says a matrix "must pass"; the gaps are 4.6-5.1 points, so any threshold below 4.5 points gives the same decisions). D2 is run only on matrices that pass. The declared S6 x D2 interaction is run on S6 regardless (PLAN3 §5 declares it), with the calibration status next to it; it is the contrast `(S6 - S3 with D2) - (S6 - S3 with D0)`, paired by race. RPS and log-loss do not depend on the decoder, so the contrast is defined for rho, MAE and exact only.

## Expected gain and failure criteria (written before the first run)
Context: M08 S3 has RPS 0.1204. The plan hopes for 1-3% (0.0012-0.0036) from all four steps together, mostly S4 and S6. M17/M18 found the matrix is cell by cell calibrated except for the grid slot, which suggests small gains here.
- **S4.** Expected RPS gain 0.0002-0.0010; fitted `m2`, `m3`, `m4` below 1. Failure: all fitted `m = 1` or the paired RPS CI includes 0. Not expected to raise exact hits or to pass the calibration gate (grid-slot probability stays near 12%); so no D2.
- **S5.** Expected RPS gain about 0 (+-0.0003); expected gain in the team log-loss 0.003-0.015 if the shared shock is real. Failure: fitted `tau_team = 0`, or the team log-loss gain CI includes 0. Exact hits not expected to move.
- **S6.** Expected RPS gain 0.0005-0.0015, larger in the first rounds of a season. Failure: fitted `c = 0` or RPS CI includes 0. Declared interaction expected NEGATIVE (the extra noise flattens the assignment problem D2 solves): exact contrast below 0; with 66 races its CI will probably include 0.
- **S7.** Expected rho change within +-0.005 and RPS within +-0.0005 (plan 2 found the order limited by information, not by the process). Failure: the fitted `(phi, rule_mult)` is the plan-2 value (0.8, 1), or both rho and RPS CIs include 0.
- With 66 races, exact-rate differences under about 2 points cannot be resolved (M17), and one 1000-draw run has about 1.2 points of simulation noise on D2 minus D0; the Monte Carlo noise of every main metric is reported from five seeds below.
- Acceptance (R12): with every new step off the simulator reproduces plan-2 S3 exactly (max |P difference| expected 0.0, bitwise).

## Leakage notes
Scores and Laplace covariances come from walk-forward fits that use races before the target race plus its own pre-race weekend signals, as plan 2. Driver experience = earlier rows of the driver; early-season flag = round number; team = constructor lineage; all known before the start. The tie-break is by driverId. S7 changes only how the car prior is penalised in the fit (rule-change seasons are a calendar fact).

## What we learned
- On dev, S3 has nothing left for these four steps to take at race level: RPS moves by at most 0.0003, inside simulation noise and inside the paired intervals. The plan's 1-3% was optimistic, and the M17 diagnosis (cell-by-cell calibration is already fine; the gap is the grid slot) predicted this.
- S4 (position-dependent discount) is not supported: the fitted stage temperatures are not a discount, and the gain is below noise.
- S5: the objective prefers independent normal noise, and a teammate shock does not help the joint metric. The plan's rationale (teammates' results move together) is not visible in this data at race level; teammate correlation may live in retirements (already modelled by M07 per entry) rather than in pace. Not tested.
- S6: parameter uncertainty improves the two log-losses a little, but the Laplace interval is not wider early in a season or after the 2022 rule change, which was the reason for the step. Treat the log-loss result as dev only.
- S7: the data prefer a random walk in car strength (phi = 1) to the plan-2 carry-over 0.8, with rho +0.007; the rule-change term adds almost nothing and 2022 does not improve. phi sits at the grid edge, the grid was not extended (budget and plan), and the fitting objective differs from the judging metric (Spearman versus RPS), as the plan reads it.
- No step touches the grid-slot gap, so decoding (M17) remains unhelpful on every one of these matrices, and the S6 x D2 interaction is null.
- Reading choices that could matter and were not varied: stage-wise fresh Gumbel draws in S4; normal marginal via the quantile map and a team shock added on the key scale in S5; Cholesky-type factor of the Laplace covariance from an unconverged 150-iteration fit and the 1/(2 lam) car prior in S6; carry-over penalty weight scaled in rule-change seasons only in S7. Tuning and judging use the same 66 races; the result is optimistic if anything.
